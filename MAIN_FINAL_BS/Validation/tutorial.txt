# environment and its own BlueSky instance, so it flies run after run. A scenario takes about
# 11 s, so the full sweep is roughly 75 h on four workers; raise --workers on a machine with
# more cores. Results go to ../Test_results_final. The no-delay models are flown with their
# response-state inputs set to zero, as in their training.
#
# Interrupted runs are safe to restart: a finished run file is skipped and a partial one is
# written as .part, so nothing half-written is ever read back.
