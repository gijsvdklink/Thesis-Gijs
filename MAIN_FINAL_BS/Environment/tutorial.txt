# Run everything from the MAIN_FINAL_BS folder:
#     cd <wherever MAIN_FINAL_BS is>
# Check you are in the right place -- this must list Environment, Training, Validation:
#     ls
#
# Every run trains on ONE environment (--n-envs 1, the default), as reported: a rollout of
# 2048 decision steps, updated as one batch of 2048 for 30 epochs. Torch runs single-threaded,
# so one run keeps about one core busy and the 21 terminals below need 21 cores. Raising
# --n-envs makes the rollout n_envs x 2048 and no longer matches the reported settings.
#
# Every run stops after 60,000 finished episodes, about 8.5e7 decision steps. That is the
# default, so no step count has to be given: --max-episodes 60000 is only needed to train a
# different length. The count is logged to TensorBoard as episode/count, and each run prints
# its progress in episodes.
#
# BlueSky flies about 140 decision steps/s per run, so 60,000 episodes take roughly a week
# per run. Check the steps/s and eta that each run prints on your own machine.

================================================================================
RESUMING AFTER A DISCONNECT
================================================================================

# Same commands, plus --resume. Each run continues from its own last checkpoint,
# keeping the step count and the TensorBoard curves continuous. At most
# --save-every steps (500,000) are lost per run.
#
# Do NOT delete ../Models. Do NOT pass --overwrite; that starts from scratch.
#
# The episode counter is NOT stored in the checkpoint: it restarts at zero, so a resumed run
# would train another 60,000 episodes. Read episode/count for that run in TensorBoard and
# pass what is left, e.g. 60000 - 41000 = 19000 -> --resume --max-episodes 19000.

# terminal 1
python Training/train.py --delay none --seed 1 --resume
