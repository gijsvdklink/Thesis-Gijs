# HIGH-DENSITY SWEEP: 30 aircraft at rho = 1/10000, 300 scenarios
#
# from the MAIN folder
#
# Normally n_aircraft is drawn per episode from randint(15, 30) and rho from
# uniform(1/20000, 1/10000), so a result is averaged over the whole range. These flags
# hold both fixed at the BUSIEST corner of it -- the most aircraft, at the highest
# density -- so the delay conditions are compared at one traffic load rather than
# across a mixture.
#
#     --n-ac 30        aircraft per scenario, instead of the draw
#     --density 0.0001 ac/km^2 (= 1/10000), so the sector is 30 / 0.0001 = 300,000 km^2
#
# Results go to Test_results_30ac, NOT Test_results, so this sweep cannot overwrite the
# baseline one. The models are read from MAIN/Models, each at its furthest checkpoint.
#
# 190 runs over 24 terminals: 22 terminals get 8 runs, 2 get 7. Use --terminals 19 for
# exactly 10 runs each. A finished scenario file is skipped on restart, so interrupting
# a terminal is safe.

python Validation/run_test_scenarios.py --terminal 1 --episodes 300 --n-ac 30 --density 0.0001 --out ../Test_results_30ac
