# Every run trains on four environments in subprocesses (--n-envs 4, the default), so one run
# keeps about five cores busy: four workers and the learner. Start only as many of the
# terminals below at once as the machine can carry.

# 1,900 steps, so that is roughly 110M steps; --timesteps 300000000 is only a ceiling that

================================================================================
RESUMING AFTER A DISCONNECT
================================================================================

# Same commands, plus --resume. Each run continues from its own last checkpoint,
# keeping the step count and the TensorBoard curves continuous. At most
# --save-every steps (500,000) are lost per run.
#
# Do NOT delete ../Models. Do NOT pass --overwrite; that starts from scratch.
#
# The episode counter is NOT stored in the checkpoint: it restarts at zero, so a resumed run
# would train another 60,000 episodes. Read episode/count for that run in TensorBoard and
# pass what is left instead, e.g. 60000 - 41000 = 19000 -> --max-episodes 19000.

# terminal 1
python Training/train.py --delay none --seed 1 --timesteps 300000000 --max-episodes 60000 --resume

# Start each run inside tmux so it keeps going without the laptop attached:
#
#     tmux new -s t1                  # one session per run
#     python Training/train.py --delay none --seed 1 --timesteps 300000000 --max-episodes 60000
#     Ctrl-B then D                   # detach; training continues
#
#     tmux ls                         # list sessions
#     tmux attach -t t1               # reattach later
#
# Or prefix a single command:
#     nohup python Training/train.py --delay none --seed 1 --timesteps 300000000 --max-episodes 60000 > t1.log 2>&1 &
