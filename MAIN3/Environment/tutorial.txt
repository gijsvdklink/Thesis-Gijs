# TRAINING: 21 runs on 21 terminals -- 3 delay types x 7 seeds
#
# Run everything from the MAIN3 folder:
#     cd <wherever MAIN3 is>
# Check you are in the right place -- this must list Environment, Training, Validation:
#     ls
#
# Each run uses 4 parallel environments (4 x 1024 = the same 4096-transition rollout one
# environment at 4096 collects), so it occupies about 4 cores. Twenty-one runs at once want
# 84. Start as many as the machine has cores for and queue the rest; --n-envs lowers it, but
# lower --n-steps to match or the update size changes with it.
#
# Results are written to MAIN3/Models/<delay type>/<delay type>_seed<N>.
