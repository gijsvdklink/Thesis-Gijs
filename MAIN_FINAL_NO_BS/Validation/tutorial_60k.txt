# 60K TEST ROUND: the retrained models (exactly 60 000 episodes), 30 aircraft at rho = 1/10000,
# 500 scenarios, 24 terminals. Written 23 Oct for the round of the final report.
#
# run from the MAIN_FINAL_NO_BS folder, AFTER training has finished:
#     cd <wherever MAIN_FINAL_NO_BS is>
#     git pull
#
# The models are read from MAIN_FINAL_NO_BS/Models: put the run directories there
# (none/, deterministic_30s/, lognormal_30s/, each with *_seed1..7).
#
# Notes:
#   - a NEW output folder, ../Test_results_60k. Finished runs are skipped, so an existing folder of an
#     earlier round would silently be reused. Do not copy any earlier runs into it.
#   - this version logs the extra test KPIs (E8): path_ratio_cut, path_ratio_manoeuvred,
#     detour_ratio_manoeuvred, secondary_conflicts, tlos_issue/exec_mean_s, los_seconds_all and the
#     executed advisories per type (<type>_executed). The existing KPIs are unchanged.
#   - the models are read from MAIN_FINAL_NO_BS/Models, each at its furthest checkpoint (final_model or
#     last_model). Training stops at exactly 60 000 episodes, so that is the 60k checkpoint; the
#     model_steps column of the results shows it.
#   - the no-delay models (N1-N7) are flown with their four response-state inputs set to zero, as in
#     their training.
#
# 1. SMOKE TEST first (a few minutes): one model in one environment, 2 scenarios, into a throw-away folder.
#    Check that it runs and that the csv has columns such as path_ratio_cut and turn_p30_executed.
python Validation/run_test_scenarios.py --run deterministic 1 deterministic 30 --episodes 2 --n-ac 30 --density 0.0001 --out ../Test_results_smoke
