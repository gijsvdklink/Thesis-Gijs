# HIGH-DENSITY SWEEP: 30 aircraft at rho = 1/10000, 500 scenarios -- 24 terminals
#
# run from the MAIN_FINAL_NO_BS folder:
#     cd <wherever MAIN_FINAL_NO_BS is>
#     git pull
#
# Normally n_aircraft is drawn per episode from randint(15, 30) and rho from
# uniform(1/20000, 1/10000), so a result is averaged over the whole range. These flags
# hold both fixed at the BUSIEST corner of it -- the most aircraft, at the highest
# density -- so the delay conditions are compared at one traffic load rather than
# across a mixture.
#
#     --n-ac 30        aircraft per scenario, instead of the draw
#     --density 0.0001 ac/km^2 (= 1/10000), so the sector is 30 / 0.0001 = 300,000 km^2
#
# The 190 runs (3 model types x 7 seeds x 9 test environments, plus no CR) are dealt out
# over 24 terminals in turn: terminals 1-22 get 8 runs, terminals 23 and 24 get 7. 190 whole
# runs cannot be split more evenly than that. Every terminal gets a mix of model types and
# delays, so no terminal has only the slow or only the fast runs.
#
# --workers 1: each terminal is ONE process and flies its runs one after another, so the 24
# terminals use 24 cores. Without it every terminal would start 4 processes, 96 in total.
#
# Results go to Test_results_nobs_30ac, so this sweep can neither overwrite nor reuse another
# one. The models are read from MAIN_FINAL_NO_BS/Models, each at its furthest checkpoint.
#
# FAIR COMPARISON: the no-delay models (N1-N7) are now flown with their four response-state
# inputs set to zero, as in their training (run_test_scenarios.py). Only their 56 runs in the
# eight delayed environments change. To fly just those, copy every other run of the previous
# round (500 scenarios, same checkpoints) into Test_results_nobs_30ac/runs first; finished runs
# are skipped, so only the 56 missing ones are flown (2 or 3 per terminal):
#
#     mkdir -p ../Test_results_nobs_30ac/runs
#     cp <previous round>/runs/D*.csv <previous round>/runs/L*.csv ../Test_results_nobs_30ac/runs/
#     cp <previous round>/runs/N*_no_delay.csv <previous round>/runs/NoCR_no_delay.csv \
#        ../Test_results_nobs_30ac/runs/
#
# A stopped terminal is resumed by giving the same command again: finished runs are skipped,
# and a half-written run is kept as .part and flown again.

# terminal 1
