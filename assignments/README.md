# Warm-up assignments

Getting back into the codebase after a break. Do them in this order.

| # | File | What | Time |
|---|---|---|---|
| 1 | [`01_build_your_own_env.md`](01_build_your_own_env.md) | Gymnasium + SB3 fundamentals. Build a small env from scratch, train PPO on it, evaluate it. | ~2.5 h |
| 2 | [`00_warmup.md`](00_warmup.md) Parts 1–2 | Python recap (data structures, functions, OOP) using your own code as the examples. | ~1.5 h |
| 3 | [`00_warmup.md`](00_warmup.md) Part 5 | Capstone: trace one `step()` through `Environments/v4/env.py`. | ~45 min |

Start with 01 even though it's numbered second — building an environment yourself is the
fastest way back in, and it makes `Environments/v4/` read like a bigger version of
something you already wrote.

Parts 3–4 of `00_warmup.md` (Gymnasium and SB3 applied to your real env) overlap with 01.
Skim them after 01 as a check rather than working through them.

Scratch work goes in `assignments/sandbox/` — gitignored, so make it yourself:

```bash
mkdir -p assignments/sandbox
```
